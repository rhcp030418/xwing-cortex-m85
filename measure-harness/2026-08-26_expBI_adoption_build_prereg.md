# 사전등록 — 실험 BI: **채택 빌드 재측정** (토글 제거)

> 작성 2026-08-26, **측정 전**. 성능 후보가 아니라 **대표값 확정** 실험이다.
> expBC §4·§6-1 이 요구한 미뤄진 항목이며, expBH §3 이 같은 요구를 반복했다.

---

## 1. 왜 필요한가

현재 채택된 세 후보는 모두 **런타임 토글 뒤에** 있다.

| 후보 | 토글 | 토글 비용 (실측) |
|---|---|---|
| X06 fixed-base comb | `mlkem_x06_mode` (연산당 1회 분기) | 무시 가능 |
| X02 `fe25519_sqr` 재스케줄 | `gen/x02_dispatch.S` (호출마다 `ldr`+`cmp`+`b`) | expBC §4: keygen 약 +4,000 cyc |
| K31 libc 워드 교체 | `k31_mode` + 카운터 (호출마다) | expBH §3: 호출당 약 84 cyc |

따라서 **지금까지의 절대값은 전부 계측 장치가 붙은 값**이며 논문 대표값으로 쓸 수 없다
(규칙 8). 토글을 걷어낸 빌드에서 다시 잰다.

## 2. 변경점

1. `fe25519_mul/add/sub` → `apx_real_*` 에 대한 **어셈블러 별칭**(`.set`)으로 바꿔
   디스패처의 `b` 한 단계를 없앤다.
2. `fe25519_sqr` → `fe25519_sqr_bb` 별칭. `x02_mode` 분기 제거.
3. `__wrap_memcpy/__wrap_memset` → **무조건 워드**. 모드 분기·카운터 제거.
4. `mlkem_x06_mode` 분기 제거 → `curve25519_scalarmult_base` 무조건 호출.

**알고리즘은 하나도 바뀌지 않는다.** 전부 분기·간접 단계 제거다.

## 3. 사전 고정 gate

### 3.1 정확성 (전부 필수 — 유일한 채택 조건)

- full X-Wing 8-seed 바이트 동일(pk/sk/ct/ss_e/ss_d) + **암묵적 거부 동일**
- FIPS 203 ML-KEM KAT, RFC 7748 X25519 KAT
- 기존 전체 하네스 `harness_fails = 0`

하나라도 어긋나면 **별칭 치환이 ABI 를 깬 것이므로 즉시 되돌린다.**

### 3.2 성능 — 대표값 확정 조건

- **BI-1: 세 연산 모두 expBH 의 B 열 이하**
  (keygen ≤ 634,890 · encaps ≤ 1,062,857 · decaps ≤ 856,837)

토글 제거는 순수한 오버헤드 제거이므로 **나빠질 수 없다.** 나빠지면 코드 배치 교란이
지배한다는 뜻이므로 그 사실을 결과로 기록하고 대표값을 확정하지 않는다.

> 이 비교는 **다른 빌드 간 파생 비교**다(규칙 7). 그래서 gate 를 "개선률"이 아니라
> "이하일 것"이라는 방향 조건으로만 둔다.

## 4. 이 실험이 하지 않는 것

- 새 최적화 없음. 새 절감률을 주장하지 않는다.
- 하네스의 과거 실험 슬롯은 그대로 둔다 — 제거하면 배치가 더 크게 바뀐다.
  **`x02_mode`·`k31_mode`·`mlkem_x06_mode` 를 쓰던 A/B 슬롯들은 이 빌드에서 무력해진다**
  (A == B). 그 슬롯의 이 빌드 출력은 **결과로 인용하지 않는다.**

## 5. 위험

1. `.set` 별칭이 `.size`/`.type` 와 충돌하거나 ITCM 섹션 배치를 바꿀 수 있다.
2. `expAM_micro.S` 가 `apx_real_*` 를 직접 부르므로 그 심볼은 **남겨야 한다.**
3. 배치 변화로 대표값이 어느 방향으로든 흔들릴 수 있다 — §3.2 가 그 방어선이다.
