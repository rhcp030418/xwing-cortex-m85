# 사전등록 — 실험 CD: **은닉 용량 곡선** (크기 고르기를 끝낸다)

> 작성 2026-08-27, **측정 전**.
> expCA(8 lane) → expCB(6) → CC-2(6, 배치 변경) 로 세 번 재단했고 매번 gate 를 못 넘었다.
> **네 번째로 크기를 고르는 대신 lane 1~8 전부를 재서 곡선을 낸다.**
> 곡선은 임계값을 넘을 때까지 고를 수 있는 것이 아니므로 gate shopping 이 아니다.

---

## 1. 재는 것

MVE 쪽은 고정: `intt layer67` 본문 ×4 = **184 MVE 명령** (측정치 A).
스칼라 쪽만 **lane = 1 … 8** 로 바꾸며 각각

| | 내용 |
|---|---|
| `A` | NTT 만 (고정) |
| `B(n)` | Keccak lane ×n 만 |
| `C(n)` | 병합 (CC-2 의 규칙 배치 사용) |

를 잰다. 배치 규칙은 **expCC §1.1 실측 표**를 그대로 쓴다(`vstrw` 옆 스칼라 금지,
`vldrw` 옆 스칼라 적재 금지).

## 2. 사전 고정 지표 — **공짜 용량 `F`**

```
F = C(n) <= A x 1.02  를 만족하는 **가장 큰 n** 에 대한 B(n)
```

`F` 는 "MVE 밑에 **공짜로** 숨는 스칼라 작업량(cyc)"이다.
2% 창은 배치 교란 통제용이며 **측정 전에 고정한다.**

부수적으로 각 n 의 은닉률 `hide(n) = (A + B(n) − C(n)) / B(n)` 을 함께 낸다.

## 3. 사전 고정 판정

- **CD-1: `F ≥ 0.60 × A`** — MVE 시간의 60% 이상을 스칼라로 공짜로 채울 수 있어야 한다.
  (expCC §2.1 이 추정한 창 205 / A 236.69 = 0.87 의 약 70%.)
- **CD-2: 어떤 n 에서도 `C(n) < A`** 가 나오면 측정 오류로 본다(불가능).
- **정확성**: 모든 n 에서 C 의 NTT 출력 = A, C 의 Keccak 출력 = B(n). mismatch 0.

**CD-1 통과 → 스티칭의 공짜 용량을 확정하고 full X-Wing 확대(CA-2)로 간다.**
**CD-1 실패 → 공짜 용량이 작다는 것을 결론으로 확정하고 W03/W04/W05 를 그 값으로 종료한다.**

어느 쪽이든 **이 실험으로 크기 고르기를 끝낸다.** 이후 재단은 하지 않는다.

## 4. 위험·한계

1. 커널 17종을 넣어야 해 **ITCM 예산을 넘는다 → 전부 `.text`** 에 둔다.
   expCA(ITCM)와 절대값이 다를 수 있으나 **A·B·C 가 모두 같은 섹션**이므로 비율 판정은 성립한다.
   이 가정은 결과에 표기한다.
2. lane 이 작을수록(1~2) 오버헤드 비중이 커져 은닉률이 흔들릴 수 있다.
3. `.text` 증가 약 18 KB 보고.
