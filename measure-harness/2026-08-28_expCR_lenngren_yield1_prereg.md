# 사전등록 — 실험 CR: Lenngren `fe25519_mul`에 r11 하나를 수동 양보한 변형의 단독 단가

> 작성 2026-08-28, **측정 전**. 출처: `paper/리뷰_v8_상위학회.md` P0-2.
> 질문: 논문의 "스티칭 가능화 비용 532k(≈2.5×)"는 Lenngren→Fiat C 교체의 비용이다.
> Lenngren 어셈블리에서 **레지스터 하나(r11)만 손으로 스필해 비우면** 곱셈 단가가 얼마나 느려지는가?
> fiat 곱셈의 양보 세금(+12.1/+12.8%, T4-b)과 같은 자릿수면 532k는 아키텍처 하한이 아니라 구현 경로의 값이다.

## 1. 대상

- A: `fe25519_mul_lenn` — 원본 `apx_real_fe25519_mul`(14 GP 레지스터 전부 사용) + AAPCS 래퍼 (expAM 정의, ITCM).
- B: `fe25519_mul_y1_lenn` — 새 `apx_real_fe25519_mul_y1`: **r11을 읽지도 쓰지도 않는다.** 같은 래퍼, 같은 ITCM 섹션.
  변환 내용(전부 손으로):
  1. 첫 반(b0..b3 × a0..a7)에서 a-limb 3개 동시 `ldm` → 한 개씩 `ldr`(레지스터 2개 확보), r11 역할 → r10.
  2. 열 4 부분합을 row 4 직후 스택에 스필(`[sp,#36]`), 둘째 반 row 0에서 재적재.
  3. 열 10 부분합을 첫 반 끝에 스필(`[sp,#44]`), 둘째 반 row 3에서 재적재.
  4. 둘째 반 a-limb 2개 동시 `ldm` → 한 개씩 `ldr`.
  5. 환원부에서 열 12가 r0에 있어 `mov` 2개 추가.
  프레임 `sub sp,#28 → #36`, 복귀 `add sp,#12 → #20`.
- 추가 명령: ldr +4(단일 적재화) + str 2 + ldr 2(스필) + mov 2 = 약 +10 명령, 그중 store 2워드.

## 2. 측정

- 슬롯 857..860 = A B B A, 861 = null(빈 루프). BATCH 64, REP_N 100 중앙값, DWT, 25-cycle 보정은 harvest에서 차감하지 않고 expBB와 같은 방식(단가 = 셀 중앙값 / 64, 래퍼 포함)으로 보고.
- 독립 flash/run 2회. 두 run의 A·B 각각 ABBA 두 값을 모두 보고.
- 입력: expBB/BD와 같은 고정 입력(a = 0x9e3779b9+i, b = 0x7f4a7c15+i).

## 3. 사전 고정 gate

### 3.1 정확성 (하나라도 실패하면 성능 수치 폐기)
- B 대 A: 경계 7쌍 + 무작위 1,000쌍 limb 단위 완전 일치 (`expCR correctness: mm=0`).
- 기존 전체 하네스 `harness_fails=0`, `KAT ALL PASS`.
- `arm-none-eabi-objdump -d` 에서 `apx_real_fe25519_mul_y1` 본문에 `r11`이 **0회** (fp 별칭 포함).

### 3.2 판정 (측정 전 고정)
- 양보 세금 `t = (B − A)/A`. **t ≤ 20%** 이면 "Lenngren에 레지스터 하나를 양보하는 비용은 fiat 양보 세금(12–13%)과 같은 자릿수이며 532k(≈150%)는 이 경로의 값"으로 원고에 기록.
- **t > 20%** 이면 그대로 기록하고 532k 문장의 한정을 유지한다. 어느 쪽이든 원고 한계 절의 "미측정" 한 줄이 실측으로 바뀐다.
- 이 실험은 U(스티치)를 다시 만들지 않는다. "Lenngren yield1 위의 U"는 여전히 미측정으로 남긴다.

### 3.3 상수시간
- 변환은 명령 순서·레지스터·고정 스택 오프셋만 바꾼다. 비밀 의존 분기·주소 없음. 두 입력의 명령 수 동일(직선 코드).
