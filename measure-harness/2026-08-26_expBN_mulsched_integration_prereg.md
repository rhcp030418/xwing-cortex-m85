# 사전등록 — 실험 BN: `fe25519_mul_sched` full X-Wing 통합

> 작성 2026-08-26, **측정 전**. 장부 ID **X01** 계열의 통합 판정.
> expBM 은 **micro 만** 쟀고 그 gate 로 X01(재스케줄 접근)을 종료했다.
> 이 문서는 **다른 질문**을 판정한다: 그 커널이 full X-Wing 에서 얼마나 회수되는가.
> expBC(X02)가 micro → full 에서 **70% 만 회수**됨을 보였으므로 결과는 실제로 미지다.

---

## 1. 알려진 것과 모르는 것

**알려진 것 (expBM 실측, 두 판 동일)**

| | cyc/호출 |
|---|---:|
| 원본 `fe25519_mul` | 156.94 |
| `fe25519_mul_sched` (평탄화 + 재정렬) | 146.94 |
| 차 | **10.00 cyc/호출 = +6.37%** |

정확성: 경계 49 + 무작위 1,000, limb 단위 **mismatch 0 / 1,049 검사**. 명령 수 120 불변.

**모르는 것**

full X-Wing 세 연산에서 실제로 얼마가 회수되는가. expBC 의 감쇠 70% 를 적용하면
encaps ≈ 1.16% 로 **투영**되지만, 그 감쇠율은 표본 하나(X02 sqr)에서 나온 값이며
mul 에도 같이 적용된다는 근거가 없다. **투영을 결과로 쓰지 않는다.**

## 2. 방법

`fe25519_mul` 심볼을 `x01_mode` 로 갈라지는 얇은 디스패처가 갖는다
(expBC 의 `x02_dispatch.S` 와 같은 형태).

```
x01_mode = 0 -> apx_real_fe25519_mul   (원본)
x01_mode = 1 -> fe25519_mul_sched      (평탄화 + 재정렬)
```

**양쪽이 같은 진입 비용을 물므로 같은 ELF 안 A/B 가 성립한다**(규칙 7).

> **주의(expBI §3)**: 이 디스패처는 호출당 45~50 cyc 을 **절대값에 얹는다.**
> 따라서 이 빌드의 절대값은 대표값이 아니며, **채택 시 디스패처를 걷어내고
> 다시 재는 것까지가 이 실험의 범위다.**

## 3. 사전 고정 kill gate

### 3.1 성능

- **BN-1: full X-Wing 세 연산 중 하나라도 회귀하면 채택 금지.**
- **BN-2: encaps 에서 ≥ 0.80% 개선.**
  (근거: mul 은 encaps 의 26.1%(expAN). 10 cyc/호출 × 약 1,644 호출 = 16.4 kcyc = 1.66%.
  expBC 의 감쇠 70% 를 적용하면 1.16%. **그 절반만 실현돼도 넘는 선**으로 0.80% 를 둔다.)
- **BN-3: decaps 에서 ≥ 0.50% 개선.** (decaps 도 ladder 를 쓴다.)

셋 다 넘어야 채택한다. 못 넘으면 **X01 계열을 완전히 종료한다.**

### 3.2 정확성 (전부 필수)

- full X-Wing 8-seed 바이트 동일(pk/sk/ct/ss_e/ss_d) + **암묵적 거부 동일**
- RFC 7748 X25519 KAT, FIPS 203 ML-KEM KAT, `harness_fails = 0`
- expBM 의 경계 49 + 무작위 1,000 limb 검사가 이 빌드에서도 mismatch 0

### 3.3 채택 시 후속 (필수)

디스패처를 제거하고 `fe25519_mul` 을 `fe25519_mul_sched` 별칭으로 바꾼 뒤
**대표값 3개를 다시 잰다**(expBI 와 같은 절차). 그 전에는 절대값을 인용하지 않는다.

## 4. 상수시간

`fe25519_mul_sched` 는 원본과 **같은 명령의 순서만 다른 것**이며 분기가 없다.
데이터 의존 분기·주소는 추가되지 않는다. 프레임이 12 B 크다.

## 5. 위험

1. 재정렬본이 ladder 문맥(다른 입력 분포·캐시 상태)에서 micro 와 다르게 동작할 수 있다 —
   그것이 이 실험이 재려는 것이다.
2. 프레임 12 B 증가로 스택 high-water 가 오른다. **보고한다.**
3. 디스패처가 절대값을 부풀린다(§2 주의). 판정은 A/B 차분으로만 한다.

## 6. 바꾸지 않는 것

곱셈 알고리즘, 커스텀 ABI, `fe25519_sqr`(X02 채택본 유지), `fe25519_add/sub`,
X25519 ladder 구조, ML-KEM/X-Wing 정의, K31(채택본 유지).
