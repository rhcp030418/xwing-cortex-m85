# 분석 BE — expBA 발행 모델로 남은 커널의 여지 상한 산정 (**K19 종료**)

> 2026-08-26. **보드 측정이 아니라 정적 분석**이다. 입력은 expBA 의 실측 발행 규칙과
> ELF 역어셈블 명령 수, 그리고 기존 실측 cycle 이다.

---

## 1. 방법

expBA 가 M85 의 스칼라 발행 규칙을 실측했다.

| | 단가 | 곱셈과의 페어링 |
|---|---:|---|
| `umaal` 등 곱셈 | 1.000 cyc | (1/cyc 처리율) |
| ALU (`adds` 등) | 0.500 cyc | 100% |
| `ldr` | 0.500 cyc | 100% |
| `str` | 0.500 cyc 단독 | **0% — 발행 차단** |

따라서 스칼라 커널의 사이클 하한은

```
하한 = (곱셈 수) + (store 워드 수) + (나머지 명령 수) / 2
```

(곱셈이 없으면 첫 항은 0. store 는 단독 점유이므로 다른 명령과 겹치지 않는다.)

이 회계는 **실측 baseline 을 재현하는 것으로 검증됐다** — expBB 에서 `fe25519_sqr` 의
모델 baseline 85 + 고정점 ≈ 96 이 실측과 맞았고, 재스케줄 예측이 실측 방향과 일치했다.

## 2. K19 — scalar Keccak-f1600: **여지 4.6%, 종료**

`KeccakF1600_StatePermute` 의 루프 몸통(0x320c~0x4998, 4 라운드)을 역어셈블해 셌다.

| | 값 |
|---|---:|
| 몸통 명령 수 | **1,526** (4 라운드) |
| 반복 | 6회 (= 24 라운드) |
| 실측 permutation | **5,504 cyc** (하네스 `[keccak-f1600]`) |
| 몸통당 | 917.3 cyc |
| **현재 IPC** | **1.66** |

명령 구성: `ldr` 437 · `str` 225 · `eor` 608 · `bic` 200 · `mov` 54
(회전은 `eor Rd,Rn,Rm,ror #k` 형태의 shifted operand 라 별도 명령이 아니다.)

```
하한 = store 225 + (1,526 − 225)/2 = 225 + 650.5 = 875.5 cyc
실측 917.3  ->  여지 41.8 cyc = 4.6%
```

**이미 발행 한계에 거의 닿아 있다.** pqm4 계보의 이 asm 은 M85 에서도 IPC 1.66 으로
돌고 있으며, store 차단을 감안한 이론 상한까지 4.6% 밖에 남지 않았다.

> **판정**: 장부 K19("scalar Keccak-f1600 을 M85 scalar dual-issue 로 재스케줄")를
> **종료한다.** expBB 의 재정렬 도구를 여기 적용해도 회수 가능한 최대가 4.6% 이고,
> 도구의 실측/예측 비가 약 0.6 이므로(expBD §3) 기대 실현치는 **2~3%** 다.
> 게다가 Keccak 은 매크로·루프 구조라 평탄화 파이프라인을 새로 만들어야 한다 —
> 투입 대비 회수가 맞지 않는다.

### 2.1 K19 종료가 K20/K21 을 닫는 것은 아니다

K19 는 **같은 명령열의 재배치**를 닫는다. 다음은 그대로 열려 있다.

- **K20** true 2-way MVE Keccak — 명령열 자체가 다르다
- **K21** matrix-XOF true x3 — 배칭 구조가 다르다
- **K24** squeeze→CBD 융합 — 경계 제거이지 재배치가 아니다
- **K22/K23** XOF 배관(absorb 11.4k / squeeze 28.7k, expAQ) — permutation 밖이다

Keccak 블록(X-Wing 의 22.4~31.3%)을 줄이려면 **permutation 을 더 빨리 돌리는 게 아니라
permutation 을 덜 부르거나 배관을 줄여야 한다.**

## 3. 한계

1. **정적 분석이다.** 하한은 발행 모델에서 나온 것이며 latency·캐시·분기는 넣지 않았다.
   실제 하한은 이보다 높을 수 있다(= 여지는 더 작다). 방향이 보수적이므로 종료 판정에는
   안전하다.
2. `str` 225 는 명령 수이며 다중워드 `stm` 이 있으면 워드 수로는 더 크다 — 그 경우
   하한이 올라가 여지가 더 줄어든다. 역시 종료 판정에 안전한 방향이다.
3. `matacc_asm_*` 와 pqmx NTT 심볼은 얇은 wrapper 로 잡혀(115 / 10 / 12 명령) 같은
   방식의 집계가 되지 않았다. **이 커널들의 여지는 미산정**이다.
4. EK-RA8M1 한 개체, 이 배치 한정.
