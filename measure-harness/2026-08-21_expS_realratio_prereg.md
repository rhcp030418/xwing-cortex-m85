# 실험 S 사전등록 — 실제 비율 A-pair 지퍼

- 질문: 실험 R의 J 개선이 실제 X-Wing 비율인 8:1과 4:1 매크로 스케줄에서도 유지되는가?
- 변경 변수: 기존 매크로 지퍼의 A 클럼프 크기만 1에서 2로 바꾼다.
- 고정 변수: A/B 명령 개수와 스트림 내부 순서, 입력, 정렬, 반복 수, 측정 방식.
- 정확성: 두 A-pair 매크로 커널을 기존 참조값 KAT에 포함한다.

각 비율에서 `(기존 지퍼 - A-pair 지퍼) / 기존 지퍼`를 판정한다.

- `>= 1%`: 실질 개선.
- `-1% < 변화 < 1%`: 실질 차이 없음.
- `<= -1%`: 실질 악화.
- 빌드·KAT·불변조건 실패는 실험 무효로 보고하며 사후 분류를 만들지 않는다.
