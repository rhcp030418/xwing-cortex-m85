# 실험 T 사전등록 — b0 + GP 무양보 fiat

측정 전 작성. 결과를 본 뒤 기준이나 분기를 바꾸지 않는다.

## 질문

기존 J는 MVE 연속 주소를 r10/r11에 두기 위해 fiat를 `-ffixed-r10,-r11`로 컴파일했고,
그 결과 fiat 단독 비용이 약 12% 증가했다. 루프 안에서 GP 베이스를 전혀 쓰지 않는 b0
개더/스캐터 커널과 GP를 양보하지 않은 fiat를 결합하면 이 세금을 회수해 기존 b2+yield2보다
실제 1:1·4:1·8:1 작업을 줄일 수 있는가?

## 단일 변경과 불가피한 보조 변경

- MVE: b2(연속 load/store, r10/r11 베이스) → b0(개더/scatter, q6/q7 주소, 루프 GP 0개).
- fiat: `-ffixed-r10,-r11` 제거. 프로젝트와 동일한 GCC 13.2.1, `-O2`, Cortex-M85 조건.
- 일반 `fiat_mul_ref`는 마지막 출력 저장에 q2/q3을 자동 사용해 b0의 q0~q7과 충돌한다.
  따라서 `-fno-tree-slp-vectorize`로 그 네 개의 MVE 출력 load/store만 스칼라화한다.
  이 옵션 자체의 비용은 `expt_fiat` 단독값과 기존 `fiat-base`를 비교해 별도로 보고한다.

## 측정 변형

- 단독: `expt_fiat`, `expt_b0`.
- 1:1: `expt_seq`, `expt_stitch`.
- 8:1(encaps 근사): `expt_m8_seq`, `expt_m8_stitch`.
- 4:1(keygen/decaps 근사): `expt_m4_seq`, `expt_m4_stitch`.
- 기존 b2+yield2의 J/M 수치를 같은 펌웨어에서 함께 재측정한다.

모든 기능 변형은 fiat 출력과 4-way Keccak 한 라운드를 C 기준값에 대조한다.
KAT 불일치 또는 `harness_fails != 0`이면 성능 결과는 무효다.

## 판정

1. `expt_fiat`가 기존 base보다 2% 넘게 느리면, 그 차이는 b0 효과와 분리해 “SLP 제거 세금”으로 보고한다.
2. 각 비율에서 `stitch < seq`이면 해당 비율에서 교차 자체는 유효하다.
3. 최종 후보는 기존 b2+yield2의 같은 비율 stitched보다 빨라야 한다.
   - 5% 이상 빠름: 강한 개선.
   - 1% 이상 5% 미만 빠름: 작은 개선.
   - ±1% 이내: 실질 차이 없음.
   - 1% 이상 느림: b0 무양보 경로는 악화.
4. 1:1만 좋아지고 4:1·8:1이 좋아지지 않으면 종단간 개선안으로 채택하지 않는다.
5. 종단간 수치는 실측 매크로 절감 사이클을 기존 전체 연산 분모
   (keygen 794,198 / encaps 1,175,479 / decaps 868,772)에 투영하며,
   기존 7.7% / 5.5% / 7.2%(평균 6.8%)와 비교한다.

## 측정 후 결과 (판정 기준은 위에서 변경하지 않음)

- 두 번의 독립 플래시/실행에서 중앙값 정확 재현. KAT·ML-KEM·모든 mismatch·`harness_fails=0`.
- no-yield fiat 273.0cyc: yield2 324.6보다 15.89% 빠름. 양보 제거 성공.
- b0 967.1cyc: b2 754.1보다 28.25% 느림. 개더 레이턴시 비용이 예상보다 큼.
- 기존 대비: 1:1 −12.06%(악화), 4:1 −5.25%(악화), 8:1 +3.20%(작은 개선).
- 같은 펌웨어의 A-pair 최선과 비교하면 8:1 개선은 2.62%.
- 판정: 전역 채택 안 함. 8:1 encaps에만 선택적 후보, 4:1 keygen/decaps는 기존 유지.
