# 사전등록 — 실험 BH (K31): libc `memcpy`/`memset` 워드 교체

> 작성 2026-08-26, **측정 전**. 장부 신규 ID **K31**. 근거: expBG §2.
> 이 문서를 쓴 시점에 **호출 수·바이트 수(분모)는 아직 모른다** — 같은 판에서 함께 잰다.
> 따라서 아래 임계값은 분모를 보고 정한 것이 **아니다.**

---

## 1. 착안

expBG 진단 실측(EK-RA8M1, 200 B 기준):

| | newlib-nano | 워드 루프 | 배수 |
|---|---:|---:|---:|
| `memset` | 614.67 cyc (3.07 /byte) | 43.09 cyc (0.22 /byte) | **14.3×** |
| `memcpy` | 2,522.75 cyc (12.61 /byte) | 442.98 cyc (2.21 /byte) | **5.7×** |

이 빌드는 `--specs=nano.specs` 를 쓴다. ML-KEM/X-Wing 은 다항식·seed·상태 복사와
영점화를 이 두 함수로 한다. **커널을 건드리지 않고 배관만 바꾸는 후보다.**

expBG 가 K22(absorb 캐시)를 종료시킨 이유가 바로 이것이다 — absorb 단가 1,211 의
50.8% 가 libc `memset` 이었다.

## 2. 방법

링크에 `-Wl,--wrap=memcpy -Wl,--wrap=memset` 를 넣고 `__wrap_*` 에서 갈라진다.

- `k31_mode = 0` → `__real_*` (newlib-nano 원본)
- `k31_mode = 1` → 워드 루프 (4바이트 정렬 시 워드, 나머지는 바이트 tail)

**양쪽 경로가 같은 wrapper 진입·분기 비용을 물므로 같은 ELF 안에서 A/B 가 성립한다**
(규칙 7). 워드 루프에는 `no-tree-loop-distribute-patterns` 를 걸어 컴파일러가 루프를
다시 `memcpy` 로 되돌려 무한 재귀가 되는 것을 막는다.

`k31_count_on` 으로 호출 수·바이트 수를 세어 **분모를 같은 판에서 기록한다**.
카운터는 A/B 측정 중에는 꺼 둔다(규칙 8 — 계측이 대상을 바꾸지 않게).

## 3. 사전 고정 kill gate

### 3.1 성능

- **BH-1: full X-Wing 세 연산 중 하나라도 회귀하면 채택 금지.**
- **BH-2: keygen/encaps/decaps 중 최소 두 연산에서 ≥ 1.00% 개선.**

둘 다 넘어야 채택한다. 못 넘으면 **K31 을 이 접근으로 종료한다.**

### 3.2 정확성 (전부 필수)

- full X-Wing 8-seed 바이트 동일(pk/sk/ct/ss_e/ss_d) + **암묵적 거부 동일**
- FIPS 203 ML-KEM KAT, 기존 전체 하네스 `harness_fails = 0`
- **정렬·길이 경계**: `memcpy`/`memset` 이 X-Wing 경로에서 비정렬·비4배수 길이로도
  불리므로 위 8-seed 동일성이 그 경로의 검증을 겸한다.

### 3.3 자원

- **BH-3: `.text` 증가 ≤ 2 KB.** 초과 시 보고하고 채택 재검토.
- stack high-water 보고.

## 4. 상수시간

워드/바이트 분기는 **주소 정렬과 길이**에만 의존하며, 둘 다 컴파일 시점에 정해지는
버퍼 배치·상수 길이다. **비밀값에 의존하지 않는다.** 데이터 값에 따른 분기는 없다.

## 5. 위험

1. 컴파일러가 wrapper 안의 루프를 `memcpy` 로 되돌려 **무한 재귀** → attribute 로 차단,
   빌드 후 역어셈블로 확인한다.
2. `--wrap` 은 **호출로 남은 것만** 잡는다. 컴파일러가 인라인한 작은 복사는 세지도,
   바꾸지도 못한다 → 분모는 **하한**이다. 결과에 명시한다.
3. FSP·startup 도 같은 wrapper 를 타므로 부팅 경로가 바뀐다. 부팅 실패 시 즉시 되돌린다.
4. 워드 루프가 정렬 안 된 큰 복사에서 바이트 tail 로 떨어지면 이득이 없다.

## 6. 바꾸지 않는 것

ML-KEM/X25519/X-Wing 알고리즘, 커널 asm, 링커 스크립트 배치, `--specs=nano.specs` 자체.
libc 의 다른 함수(`memmove`, `strlen` 등)는 이 실험에서 건드리지 않는다.
