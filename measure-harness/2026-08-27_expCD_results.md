## 2. 초판이 왜 틀렸나 — **q 레지스터 초기화 누락**

초판은 전 lane 에서 NTT 출력이 **정확히 64 B**(= 한 iteration 의 저장 블록) 어긋났다.

원인 추적:

1. `expcd_c6` 와 expCC 의 `expca_merged` 를 역어셈블로 대조 → **425/425 명령 완전 일치**.
   병합 로직은 무죄.
2. **자가검사**: 같은 커널 `expcd_a` 를 두 버퍼에 돌려 비교 → **64 B 불일치**.
   병합과 무관함이 확정.
3. 원인: `layer67` 본문의 첫 명령이 `vmla.S16 q3, q4, r12` 이고, 이는 **이전 iteration 의
   q3/q4** 를 쓴다(SLOTHY 소프트웨어 파이프라인). 프롤로그가 q 를 초기화하지 않아
   **첫 iteration 의 출력 64 B 가 호출 직전 벡터 상태에 좌우**됐다.
4. 프롤로그에 `vldrw` 8개로 q0–q7 을 결정적으로 채우자 **전부 0** 이 됐다.

> **expCA·expCB·expCC 의 `mm = 0` 은 운이었다.** 그 판들도 q 를 초기화하지 않았고,
> 호출 순서가 우연히 같은 q 상태를 만들었을 뿐이다. **프롤로그를 고친 뒤 expCA 도
> 다시 `mm = 0` 임을 확인했다**(같은 빌드, `expCA correct: ntt-mm=0 kec-mm=0`).
> 성능 수치는 프롤로그가 8 명령 늘어난 만큼 달라진다 — **A 236.69 → 238.44.**

## 3. 곡선 (정확성 통과, 두 판)

`A` = `intt layer67` 본문 ×4 = **238.44 cyc** (MVE 184 명령).

| lane | `B(n)` 스칼라만 | `C(n)` 병합 | `C − A` | **은닉률** |
|---:|---:|---:|---:|---:|
| 1 | 80.44 | 250.44 | **12.00** | **85.1%** |
| 2 | 114.25 | 264.44 | 26.00 | 77.2% |
| 3 | 146.44 | 272.25 | 33.81 | 76.9% |
| 4 | 180.25 | 286.44 | 48.00 | 73.4% |
| 5 | 212.44 | 286.44 | 48.00 | 77.4% |
| 6 | 246.25 | 312.25 | 73.81 | 70.0% |
| 7 | 278.44 | 334.25 | 95.81 | 65.6% |
| 8 | 312.25 | 362.44 | 124.00 | 60.3% |

두 판의 차이는 lane 4 한 곳(300.00 → 286.44)뿐이고 나머지는 완전 일치했다.
**보수적으로 큰 값을 쓴다.**

### 3.1 읽는 법

- **공짜(2% 창)는 어느 크기에서도 없다.** lane 1(스칼라 80 cyc)에서도 12 cyc 이 샌다.
- **누출은 스칼라 작업량에 대략 비례한다**: `C − A ≈ 0.15~0.40 × B`.
- **은닉률은 60~85%** 이고 스칼라가 커질수록 떨어진다(MVE 창을 넘어서기 때문).
- lane 4·5 가 같은 `C` 를 내는 것은 배치 규칙이 만든 계단이다.

## 4. 그래서 스티칭의 실질 이득은 얼마인가 (**파생 추정**)

```
병합 시간 C ≈ A + k·B,   k = 0.15 ~ 0.40 (스칼라/MVE 비에 따라)
순차 시간   = A + B
절감        = (1 − k)·B  =  B 의 60~85%
```

X-Wing 에 적용하면(MVE 창 = NTT+invNTT, expAP 실측):

| 연산 | MVE 창 | 스칼라를 창의 1.3배까지 넣고 k=0.40 가정 | 해당 연산 중 |
|---|---:|---:|---:|
| keygen | 29,958 | 23,367 | **3.73%** |
| encaps | 24,814 | 19,355 | **1.96%** |
| decaps | 37,745 | 29,441 | **3.78%** |
| | | | **평균 3.16%** |

> **이는 추정이다.** 실제 X25519 커널은 Keccak extract 보다 메모리 비중이 높아
> `k` 가 더 클 것이다(expCC: MVE 저장은 스칼라를 통째로 막는다). **full X-Wing 은 미측정.**

## 5. 사전등록 판정과 이 추정의 관계 — 섞지 않는다

**CD-1 은 "공짜 용량"을 물었고 답은 0 이다.** 사전등록대로 W03/W04/W05 를 종료한다.

§4 의 3.16% 는 **공짜가 아니라 "60~85% 할인"** 이다. 두 개념을 섞어
"그래도 3% 는 되니까 계속하자"고 하지 않는다. 계속하려면 **새 사전등록**으로
"할인율 기준"의 새 임계값을 세워야 한다.

## 6. 미측정·한계

1. **full X-Wing 통합은 하지 않았다.** §4 는 커널 수준 곡선의 외삽이다.
2. 스칼라 스트림은 **Keccak extract 한 종류**다. `fe25519_mul` 로 바꾼 곡선은 미측정.
3. MVE 쪽은 `intt layer67` 한 루프다. 다른 루프(`layer45` 7 레지스터 등)는 미측정.
4. lane 4 의 두 판 차이(300.00 / 286.44) **원인 미규명**.
5. 커널 17종이 `.text` 에 있다(ITCM 예산). expCA(ITCM)와 절대값이 다르다.
6. EK-RA8M1 한 개체, 이 배치 한정.

   당시 검증은 불충분했다.**
