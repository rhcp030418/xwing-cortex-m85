# 실험 R 사전등록 — A-pair(2:1) 지퍼

- 질문: 실험 Q의 잔여 노출 113사이클은 1:1 지퍼가 A의 자기 듀얼이슈를 없앤 결과인가?
- 변경 변수: A 명령을 한 개가 아니라 연속 두 개씩 묶는다. `zip_streams`가 모든 B 명령을 이 묶음들 사이에 균등 분산한다.
- 고정 변수: A/B 명령 개수, 각 스트림 내부 순서, 입력, 정렬, 반복 수, 측정 방식.
- 주 실험: store 제거형 Q에 같은 A-pair 배치를 적용한다. 원본 J의 A-pair 결과는 실제 성능에 대한 부수 결과로 함께 보고한다.
- 정확성: 기능 등가인 J A-pair는 기존 참조값 KAT에 포함한다. Q는 기존과 동일하게 측정 전용이며 KAT 대상이 아니다.

판정량은 `F = (Q 1:1 노출 - Q A-pair 노출) / Q 1:1 노출`이다.

- `F >= 50%`: 자기 듀얼이슈 상실이 잔여 노출의 지배적 원인이라는 강한 지지.
- `10% <= F < 50%`: 부분 기여.
- `-10% < F < 10%`: 실질적 효과 없음.
- `F <= -10%`: A-pair 배치가 악화하므로 가설 반증 또는 다른 병목 지배.
- 빌드·KAT 실패, 명령 수/순서 불변 어서션 실패 등은 결과를 재분류하지 않고 실험 무효로 보고한다.

주의: 전체 A:B 명령 수는 알고리즘이 정하므로 바뀌지 않는다. 여기서 2:1은 A를 두 명령씩 인접시키는 로컬 배치이며, 실제 출력에서는 B가 2~3개씩 사이에 배치될 수 있다.
