# 사전등록 — 실험 DB: 실제 U의 네 조각 전체 솔버 재스케줄과 r2–r9 제한 해제

> 작성 2026-08-28, **솔버 실행·후보 빌드·측정 전**. 출처: expCS 결과 §5–6의 두 미측정 항목.

## 1. 질문

expCS는 `fiat_mul_u4_p0` 한 조각만 재스케줄했고, Armv8.1-M `LSLL/LSRL`의 짝수/홀수 레지스터 쌍 제약이 모델에 없어 r2–r9를 재할당 금지했다. 이 두 제한을 제거해도 네 조각 전체 U 솔버 후보가 순차 F를 이기는가?

## 2. 모델·후보 고정

- SLOTHY의 `args_in_out_combinations`를 사용하여 `LSLL/LSRL RdLo,RdHi,#imm`의 허용쌍을 `(r0,r1)`, `(r2,r3)`, …, `(r10,r11)`로 제한한다.
- r11은 MVE b1 베이스, q7은 개더 베이스라 기존처럼 예약한다. **r2–r9 추가 예약은 제거**한다.
- `fiat_mul_u4_p0`부터 `p3`까지 네 조각을 각각 expCS와 같은 안전변환(ldrd/strd 분해, 스필 슬롯 고유화, MVE 메모리 모델 v0.6) 뒤 split heuristic으로 재스케줄한다.
- 각 조각에 대해 변환 대조군 `Ut`(변환 후 원래 순서)과 솔버 후보 `Us`를 만든다.
- F/U/Ut/Us/Us/Ut/U/F, REP_N=100, 독립 flash 2회. expCS의 격리된 24-round u4 배치 벤치와 동일 작업량을 사용한다.

## 3. 게이트

하나라도 실패하면 성능값을 폐기한다.

1. 네 솔버 출력 모두 어셈블·링크 성공; `LSLL/LSRL` 목적지 쌍이 전부 허용쌍.
2. 솔버 창 selfcheck 전부 통과; 제한 없는 최종 출력에서 r2–r9 재할당이 실제 허용됐음을 설정 로그로 확인.
3. 각 반복 Keccak 상태 800 B와 X25519 출력 대 순차 참조 mismatch 0.
4. `KAT ALL PASS`, `harness_fails=0`.

## 4. 판정

- 주 판정은 두 순서 모두 `Us−F < 0`인가이다. 그러면 전체 솔버 후보가 순차보다 빠르다.
- 하나라도 `Us−F >= 0`이면 음성 결과로 판정한다.
- `Us−U`, `Us−Ut`, `Ut−U`를 함께 보고하여 실제 스케줄 효과와 안전변환 세금을 분리한다.
- 예측: phase-0에서 원시 스케줄 이득은 호출 24회당 약 1.2k였고 변환 세금이 약 1.9k였다. 네 조각 전체를 풀면 어느 쪽도 단순 4배라고 가정할 수 없으나, Us가 F보다 느릴 것으로 예측한다.
