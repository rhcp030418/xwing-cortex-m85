# 사전등록 — 실험 BB (X02): `fe25519_sqr` 재스케줄

> 작성 2026-08-26, **측정 전**. AZ 사전등록의 §3(SLOTHY 직접 투입)을 대체한다.
> 선행: expBA(M85 발행 규칙 실측), expAY(분모), expAR/AS(단가).

---

## 1. 실측으로 확정된 하한

expBA 가 M85 의 발행 규칙을 직접 쟀다.

| | 단가 | umaal 과의 페어링 |
|---|---:|---|
| `umaal` | 1.000 cyc | — (1/cyc 처리율) |
| `adds` | 0.500 cyc | **100%** |
| `ldr` | 0.500 cyc | **100%** |
| `str` | 0.500 cyc | **0% (완전 차단)** |

`fe25519_sqr` = 94 명령 = 곱셈 53 + store 6명령(14워드) + load 4 + ALU 32.

```
하한 = 곱셈 53 + store 14워드 = 67 cyc      (현재 본문 ~96)
여지 = 29 cyc = 30.2%
```

ALU 32 + load 4 = 36 개는 곱셈 53 슬롯 옆에 전부 들어간다(36 < 53).

## 2. 방법 — 재정렬 전용 리스트 스케줄러

SLOTHY 는 쓰지 않는다. `slothy-2stream/README` §135 의 확정 원칙대로 14레지스터를
꽉 채운 손 asm 은 스필 추가 없이 스케줄러가 손대지 못하며, **레지스터 재할당을 하는
순간 이 커널의 ABI(입출력 r0–r7)가 깨진다.**

대신 **순서만 바꾸는** 도구를 만든다.

- 레지스터 재할당 **없음**, 명령 추가·삭제 **없음** → 의미 보존이 의존성 그래프의
  정확성만으로 보장된다.
- 의존성: 레지스터 RAW/WAR/WAW + **플래그**(`adds`/`adcs`/`subs`/`movs` 는 write,
  `adcs`/`sbcs` 는 read) + 메모리(같은 `[sp,#k]` 는 순서 보존, 다른 오프셋은 독립).
- 목표 함수: 매 사이클 `곱셈 1 + 비곱셈 1`, store 는 단독 점유.

### 2.1 절대 건드리지 않는 것

- `push`/`pop`/`sub sp`/`add sp` 는 **고정점**으로 두고 그 사이 구간만 재정렬한다.
- 함수 진입·복귀 코드
- 명령 자체(피연산자·레지스터 이름)

## 3. 사전 고정 kill gate

### 3.1 정확성 (전부 필수, 하나라도 실패하면 즉시 폐기)

- 재스케줄본 대 원본: **무작위 1,000 입력 limb 단위 완전 일치**
  (경계 포함: 0, 1, p−1, p, 2^255−1, all-ones, 2^256−1)
- RFC 7748 X25519 KAT 4종
- full X-Wing 8-seed 바이트 동일 + 암묵적 거부 동일
- 기존 전체 하네스 KAT·mismatch 0

### 3.2 성능

- **BB gate: `fe25519_sqr` 단독 단가가 5% 이상 줄어야 한다.** 못 넘으면 X02 종료.
  (여지 30.2% 의 약 1/6. 이만큼도 못 얻으면 발행 모델이 이 커널에 안 맞는 것이다.)
- full X-Wing 에서 **하나라도 회귀하면 채택 금지.**
- **스케줄러 예측과 보드 실측의 괴리를 반드시 기록한다.**

### 3.3 자원

- 명령 수 **불변**이어야 한다(재정렬 전용). 늘어나면 도구 버그다.
- 코드 크기·ITCM working set 보고.

### 3.4 상수시간

- 재정렬은 데이터 의존 분기·주소를 만들지 않는다. 스칼라 all-zero/all-ones 분포 겹침 확인.

## 4. 위험

1. **플래그 의존성 모델링이 틀리면 조용히 오답이 난다.** 이 커널은 `adds`→(umaal 여러 개)
   →`adcs` 처럼 **캐리를 멀리 물고 간다**. 플래그 write/read 를 잘못 잡으면 KAT 이
   깨지겠지만, 특정 입력에서만 깨질 수도 있다 → 1,000 seed + 경계값이 방어선이다.
2. `umaal` 은 flag 를 쓰지 않는다는 가정에 의존한다. (ARM ARM: UMAAL 은 플래그
   미변경. 이 커널이 캐리를 umaal 너머로 보존하는 구조 자체가 그 증거다.)
3. 메모리 별칭: `[sp,#k]` 오프셋이 서로 다르면 독립으로 본다. `strd` 는 2워드를
   덮으므로 폭을 정확히 계산해야 한다.
4. 재정렬이 I-cache 라인 경계를 바꿔 배치 효과가 섞일 수 있다 — AF 판례대로 통제한다.

## 5. 바꾸지 않는 것

field 표현(8×32), 알고리즘, 감산, 함수 ABI(입출력 r0–r7, sp 불변, `bx lr`),
호출 지점, X06 comb, ML-KEM 경로.
