## 실험 A 결과 — 솔버가 2-스트림을 스스로 교차한다 ✅

입력(`exp_a.s`): 곱 조각(umull/umaal + adds/adcs/adc 캐리 체인) 뒤에 Keccak θ 조각
(메모리 상주)을 **순차 연접**한 17명령. 출력(`exp_a_opt.s`):

- **9사이클, IPC 1.89 = 사이클 하한 도달 (OPTIMAL, 벽시계 0.27초)**
- 매 사이클 A·B 명령 페어링 (cycle0: ldr∥umull …) — 의존성 기반 자동 교차
- **스트림 간 레지스터 재할당**: B 값을 A가 비운 레지스터로 자동 이동 (지퍼 v0.3 불가능 영역)
- 캐리 플래그 체인(adds→adcs / adds→adc) 합법성 보존 — FLAGS를 의존성으로 모델링한 효과
- 보드 실측 IPC(합성 교차 1.99)와 정합하는 예측

## 실험 N — 페어링 스펙트럼 + 모델 v0.4 ✅ (2026-08-17) — 천장 원인 확정

### 실험 N2 — 2:1 비율 + LSU 혼합 (슬롯 72~76): 합성 클래스 분해
