# Cortex-M85 X-Wing 자원 비용 감사

기준일: 2026-08-31  
목적: 논문 `ko/main.tex`의 결합 계측 이미지와 경로별 최소 배포 프록시를 구분하고,
ELF/MAP·보드 stack 결과와 표의 모든 바이트 값을 대조한다.

## 판정 경계

- `expCJ`는 A/B·reference·측정 코드를 함께 링크한 **결합 계측 이미지**다. 전체 section과
  공통 stack 값은 재현 가능하지만 A/B 배포 증분은 아니다.
- `expDE`는 같은 BSP·링커·컴파일 옵션·newlib-nano·draft-10 API·시험 RNG를 유지하고
  런타임 dispatcher, 반대 경로와 계측 코드를 제거한 **독립 최소 배포 프록시**다.
- footprint는 `arm-none-eabi-size --format=berkeley`의 `text/data/bss`로 산출한다.
  비휘발은 `text+data`, 정적 RAM은 `data+bss`다.
- stack은 footprint와 다른 canary 진단 이미지에서 보드 측정했다. 그러므로 canary와 KAT
  작업 버퍼가 footprint의 `bss`에 섞이지 않는다.
- `expDE` 절대값에는 BSP, 1,024 B main stack, 결정적 시험 RNG가 공통 포함된다. 순수
  라이브러리 크기나 타 플랫폼 수치로 해석하지 않는다.
- `expDJ`는 최초 A0와 최종 B8을 한 이미지에 둔 **최종 직접 비교 이미지**다. 경로별
  stack은 비교 wrapper를 포함하고, 결합 ELF 크기는 A0/B8·시험 배열을 함께 포함하므로
  dispatcher-free 최종 배포 footprint가 아니다.

## 독립 최소 배포 프록시 확인값

| 모드 | text | data | bss | 비휘발 `text+data` | 정적 RAM `data+bss` |
|---|---:|---:|---:|---:|---:|
| A 기준형 | 30,756 B | 4 B | 1,470 B | **30,760 B** | **1,474 B** |
| B 최종형 | 63,028 B | 2,040 B | 1,474 B | **65,068 B** | **3,514 B** |
| B−A | +32,272 B | +2,036 B | +4 B | **+34,308 B (+111.53%)** | **+2,040 B (+138.40%)** |

산술 대조:

- A 비휘발: `30,756 + 4 = 30,760`; B 비휘발: `63,028 + 2,040 = 65,068`.
- A 정적 RAM: `4 + 1,470 = 1,474`; B 정적 RAM: `2,040 + 1,474 = 3,514`.
- 비휘발 차이: `65,068 − 30,760 = 34,308`; 정적 RAM 차이:
  `3,514 − 1,474 = 2,040`.
- `x25519_base_comb = 0x8100 = 33,024 B`이고, `33,024 / 34,308 = 96.25%`다.
- B의 추가 초기화 RAM 중 후보 NTT/INTT `.data`는 각각 1,016 B, 합계 2,032 B다.

## 경로 제거·재링크 재현성

| 게이트 | A | B |
|---|---|---|
| 반대 경로 제거 | 후보 mul/sqr, comb 표, 후보 NTT/INTT 없음 | baseline mul/sqr, baseline NTT/INTT 없음 |
| build 1/2 ELF SHA-256 | `811FEE85…D42D1`로 일치 | `A5F16F10…AA292`로 일치 |
| 해석 | dispatcher-free 기준형 | dispatcher-free 최종형 |

엄격 최소 링크에서는 monolithic assembly의 section을 경로별로 나누고 명시적 생산 객체
manifest를 사용했다. 결합 프로젝트의 ITCM wildcard에 의존한 첫 분리 빌드는 미사용
section까지 잔존하므로 최소 footprint 정본에서 제외했다.

## 보드 stack high-water

두 모드 모두 공식 draft-10 vector mismatch 0, 8-seed smoke mismatch 0, 변조 ciphertext
warm/cold mismatch 0, 하단 64 B guard 훼손 0을 통과했다.

| 연산 | A | B | B−A |
|---|---:|---:|---:|
| keygen | 9,176 B | 9,176 B | 0 B |
| encaps | 6,664 B | 6,664 B | 0 B |
| decaps-warm | 6,600 B | 6,600 B | 0 B |
| decaps-cold | **10,264 B** | **10,264 B** | 0 B |

이는 평가한 네 경로와 canary 방법에서의 관측 high-water다. 모든 입력에 대한 정적 최악
stack 증명은 아니다.

## 최종 직접 비교와 2단계 연결 심볼 상계

expDJ의 다섯 독립 재플래시에서 A0와 B8의 경로별 high-water와 64 B guard를 함께
검사했다.

| 연산 | A0 | B8 | B8−A0 |
|---|---:|---:|---:|
| keygen | 10,360 B | 10,360 B | 0 B |
| encaps | 7,848 B | 7,848 B | 0 B |
| decaps-warm | 7,784 B | 7,784 B | 0 B |
| decaps-cold | **11,448 B** | **11,448 B** | 0 B |

모든 guard 훼손은 0이었다. 이 수치는 비교용 mode 조회와 공통 wrapper를 포함하므로
expDE dispatcher-free 10,264 B를 대체하지 않는다.

expDJ 결합 ELF의 Berkeley `text/data/bss`는 113,908/3,068/354,596 B다. 연결 MAP의
retained 심볼을 보수적으로 합하면 2단계 지원 코드 상계는 다음과 같다.

| 항목 | 바이트 |
|---|---:|
| `curve25519_scalarmult` 증가(0x358→0x426) | 206 |
| MVE cswap helper | 24 |
| paired/zero-safe helper | 92 |
| fixed projective helper | 264 |
| paired batch helper | 320 |
| veneer | 16 |
| **연결 코드 상계 합** | **922** |
| 실험 mode 상태 (`bss`) | **4** |

922 B는 연결 심볼의 보수적 코드 회계다. 공통 코드 성장과 helper를 보여 주지만 dead-code
제거·배치가 확정된 dispatcher-free B8의 정확한 순증가가 아니다. 따라서 본문은
“922 B 코드 상계·4 B 상태”로만 보고하고 최종 배포 footprint는 미측정으로 남긴다.

X06 표를 제거하는 1단계 선택지는 flash 33,024 B를 절약하는 대신 keygen/encaps/cold에
각각 151,802–152,860 / 151,676–152,710 / 151,838–152,732 cycle을 되돌린다. warm은
−56–+16 cycle로 잡음 규모다. paired inversion은 X06이 생성한 두 점을 이용하므로 이
수치를 X06 없는 최종 B8의 Pareto 점으로 확대하지 않는다.

## 본문 반영 규칙

1. 최초 A0→최종 B8의 주 총효과는 expDJ 직접 동일 ELF의
   19.52/19.75/11.66/15.48%만 쓴다.
2. 30,760/65,068 B와 1,474/3,514 B는 expDE의 동일 조건 최소 배포 프록시끼리만
   비교한다.
3. expCJ 결합 section과 expDE A/B 값을 감산하지 않는다.
4. 33,024 B fixed-base 표를 시간--공간 비용의 지배 항으로 함께 보고한다.
5. expDJ stack과 922 B 연결 코드 상계는 최종 dispatcher-free 배포형 수치로 부르지 않는다.
6. 순수 라이브러리 크기, 타 플랫폼 정규화 Pareto, 전력·에너지 효율은 주장하지 않는다.
