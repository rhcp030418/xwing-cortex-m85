# A주제 논문 최종 재심사 — 영문 문체 제외

대상은 `paper/ko/main.tex`에서 다시 만든 24쪽 LNCS PDF다. 영문 문체·영문 교정은 이번
판정에서 제외했다. 수치, 실험 설계, 주장-증거 대응, 구조, LNCS 빌드와 재현성만 심사했다.

## 판정

**조건부 약한 채택(Weak Accept), 영문 심사와 투고처 분량 규정 확인 전까지 제출 보류.**

이제 기술적 Major Revision 사유는 없다. 33/43 최대 커버리지 후보와 Lenngren y1 종단간
후보를 실제 보드에서 직접 구현·측정했고, 전체 솔버 후보의 정확성 실패도 성능값과 분리했다.
음성 결과의 핵심 대안 설명을 측정으로 막았으므로 논문으로서 완결성이 생겼다. 다만 한 보드
개체뿐이고, 정확한 전체 솔버 성능은 여전히 미측정이며, 투고처가 24쪽 미만을 요구하면 형식상
탈락한다.

| 심사 항목 | 점수(5점) | 판정 |
|---|---:|---|
| 측정 엄밀성 | 4.6 | 직접 보드 측정, ABBA, 정확성 선행 게이트, 폐기 기준이 명확함 |

## 이번에 바로잡아 보강한 것

1. 서로 다른 후보를 모두 `U′`로 부르던 기호 충돌을 제거했다. 커버리지 후보는
   `U_3/U_5/U_9/U_11`, Lenngren y1 후보는 `S_L/U_L`로 분리했다.
2. 33/43=76.7% 후보의 네 대응값을 표로 승격했다. `U_11−F_11`은
   153,060–153,157 cycle, 10.9689–10.9755%다.
3. Lenngren y1 종단간 후보의 두 플래시·세 연산·AB/BA 열두 값을 표로 승격했다.
   모든 값에서 `U_L−S_L>0`이며 손실은 3.9410–5.7534%다.
4. 전체 솔버 후보는 비별칭 출력과 MVE 상태는 맞지만 출력/입력 별칭에서
   p0–p3별 64/96/94/32바이트가 틀렸음을 표로 분리했다. 이 후보의 cycle은 폐기했고
   정확한 전체 솔버 성능은 미측정으로 유지했다.
5. F/U 7회 재플래시는 연산별 14개, 세 연산 합계 42개 대응효과다. 이전의 `스무`와
   `스물여덟`은 F/U 셀값 개수와 대응효과 개수를 혼동한 표현이므로 폐기했다.
6. 커버리지 두 표를 하나로 합쳐 float 전용 빈 페이지를 없앴다. 원고는 25쪽에서
   24쪽으로 줄었다.

## 수치 재검산

- F/U 동결본 7회 재플래시의 실제 대응효과: keygen 1.976712–1.986796%,
  encaps 3.713731–3.719022%, decaps 1.877548–1.882057% 악화. expCZ는 expCV의
  keygen·decaps 범위 하단을 각각 0.000791%p·0.000491%p 넓혔다.
- 33/43 후보: 표의 네 F/U 값, 차분, 백분율이 `2026-08-28_expDA_results.md`와 일치한다.
- 전체 솔버: 144/144 OPTIMAL, 내부 selfcheck 통과, alias mismatch와 cycle 폐기가
  `2026-08-28_expDB_results.md`와 일치한다.
- Lenngren y1: 두 플래시의 여섯 AB/BA 차분과 백분율이
  `2026-08-28_expDC_results.md`와 일치한다.
- 보드 간 재현성, 완전 전원 재인가, 에너지, 정확한 alias-aware 전체 솔버 성능은
  결과가 아니라 `미측정`으로 남아 있다.

## LNCS·산출물 검사

- `llncs` 클래스와 `splncs04` 참고문헌 스타일을 사용한다.
- XeLaTeX/BibTeX 격리 빌드: 24쪽, 오류 0, 미정의 인용·참조 0, overfull box 0,
  불안정 교차참조 0.
- 표와 그림은 렌더링된 전 24쪽에서 잘림·겹침·빈 float 페이지가 없다.
- PDF 글꼴 27개는 모두 embedded다.
- Overleaf 업로드 ZIP은 격리 재빌드에 성공했다.
- 아티팩트 ZIP은 724개 파일과 최상위 SHA-256 manifest를 포함하며 재검증에 성공했다.

## 남은 심사 위험

### 제출 전 필수

- **행사별 페이지 상한 확인.** Springer 자체는 논문 최대 쪽수를 정하지 않고 학회가 정한다.
  목표 행사가 24쪽보다 짧게 제한하면 현재 원고는 내용과 무관하게 형식 탈락이다.
- **영문 심사.** 이번 판정에서 의도적으로 제외했다. 영문판이 정본과 수치·표·참조까지
  동기화된 뒤 별도 심사가 필요하다.
- **저자 정보.** 블라인드 심사본이면 현재 익명 표기가 맞지만 camera-ready라면 실제 저자,
  기관, 교신저자 이메일로 바꿔야 한다.

### 한계이나 현재 주장과 충돌하지 않음

- 보드 한 대의 독립 플래시 반복이므로 다른 M85 개체·SoC에 대한 일반화는 제한된다.
- 전체 솔버의 정확한 성능은 측정되지 않았다. 원고가 이를 느리다고 주장하지 않으므로
  내부 정합성은 지켜졌다.
- 스톨 원인은 PMU 부재로 가법 분해되지 않았다. 현재 원고는 후보 병목으로만 표현하므로
  과장은 없다.
- 최종 제작 단계에서는 그림의 대체 텍스트와 접근성 요구를 출판사·편집자 지침에 맞춰
  확인해야 한다.
